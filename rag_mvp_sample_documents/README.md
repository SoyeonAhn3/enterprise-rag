# Enterprise RAG Assistant — 가상 업무 문서 세트

이 자료는 **가상 기업 '가온비즈'**의 사내 구매·결재·보안·계약 업무 문서를 본떠 작성한 **RAG 데모 전용 합성 문서**입니다. 실제 기업의 내부 규정이나 법률 자문이 아닙니다.

## 파일 구성

| PDF | 문서명 | 문서 ID | 설계된 주제 |
|---|---|---|---|
| `01_purchase_process.pdf` | 구매요청 및 발주 업무지침 | GB-PUR-01 | 요청서, 비교견적, 발주, 검수, 긴급 구매 |
| `02_approval_budget.pdf` | 결재권한 및 예산통제 규정 | GB-APR-02 | 금액별 결재권자, 예산 검토, 구매 분할 금지 |
| `03_it_security.pdf` | IT 자산 및 SaaS 보안검토 지침 | GB-SEC-03 | IT 사전 보안, 무료 SaaS, 위험도, 자산 등록 |
| `04_contract_settlement.pdf` | 계약 검토·검수·정산 업무가이드 | GB-CON-04 | 법무 검토, 계약, 검수, 증빙, 지급일 |

총 **13쪽**의 텍스트 기반 PDF로, 스캔/OCR 없이 PyMuPDF로 추출 가능합니다.

## MVP에 활용하는 방법

1. 4개 PDF를 프로젝트의 `documents/` 디렉터리에 넣습니다.
2. 각 PDF를 **페이지별로 텍스트 추출**하며 `source_file`과 `page` 메타데이터를 남깁니다.
3. Chunking(예: 800자 / Overlap 120자), Embedding, Chroma 인덱스를 구축합니다.
4. 사용자 질문 시 Top 3 Chunk를 검색해 LLM에 전달합니다.
5. 답변과 함께 **실제 문서명·1-based 페이지 번호**를 표시합니다.
6. `eval/questions.json`에는 단일 문서 질문 6개, 여러 문서 결합 질문 2개, 답변 불가능한 질문 2개가 들어 있습니다.

## 평가 주의사항

- `eval/questions.json`은 **테스트 전용 정답지**이므로 벡터 DB에 색인하지 말고 RAG 답변 생성에 제공하지 마세요.
- `evidence_groups`는 답변에 필요한 **정보별 필수 근거 그룹**입니다. 그룹 사이는 **AND**, 각 그룹의 `any_of` 후보 사이는 **OR**입니다. 후보를 모두 검색할 필요는 없습니다.
- 각 그룹의 `claim`은 확인할 사실이며, 후보의 `document`, `page`, `quote`는 각각 PDF 파일명, 1-based 페이지, 해당 사실을 뒷받침하는 원문 발췌입니다. 같은 페이지의 다른 문장도 별도 후보가 될 수 있습니다.
- 예를 들어 q03의 검수 기한은 `04_contract_settlement.pdf` 2쪽 **또는** `01_purchase_process.pdf` 3쪽으로 확인할 수 있습니다. q07은 결재권자 그룹과 보안검토 그룹이 **모두** 필요하며, 보안검토 근거는 `03_it_security.pdf` 1쪽 또는 3쪽을 인정합니다.
- **Retrieval Hit@3**는 답이 있는 8문항 중 Top 3에 후보의 문서+페이지가 하나 이상 포함된 질문의 비율입니다. 같은 페이지의 여러 후보가 적중해도 해당 질문은 한 번만 집계합니다.
- **Multi-document Coverage**는 q07·q08 각각에서 모든 필수 그룹의 후보 페이지가 하나 이상 검색됐는지 기록합니다. q06처럼 단일 문서 질문에도 여러 필수 정보 그룹이 있을 수 있습니다.
- 페이지 적중과 실제 근거 확보는 다릅니다. 검색된 Chunk에 해당 사실을 뒷받침하는 문장이 있는지 수동 확인하세요. `quote`의 줄바꿈·공백 차이는 정규화할 수 있지만, 문장 전체의 문자열 일치만으로 답변 정오를 결정하지 않습니다.
- `expected_answer`는 검토용 참고 설명이며 반드시 그대로 재현해야 하는 출력 템플릿이 아닙니다. `grading_criteria`의 필수 조건을 충족하고, 답변의 핵심 주장이 실제 검색 근거로 뒷받침되는지 사람이 채점합니다. 검색되지 않은 원문의 사실을 덧붙인 답변은 근거 충실도 확인이 필요합니다.
- `answer_keywords`는 검토 보조용입니다. 띄어쓰기·동의어·부정문·숫자 부분 일치 때문에 오판할 수 있으므로 키워드 포함 여부만으로 자동 정답 처리하지 마세요.
- '답변 불가능' 질문은 검색 결과가 0개임을 의미하지 않습니다. 유사 문서가 검색되더라도 근거가 없으면 답변을 보류해야 합니다.
- `answerable: false`인 q09·q10은 `evidence_groups`가 빈 목록입니다. 검색 적중률과 다중 문서 Coverage에서 제외하고 보류 여부를 평가하며, 빈 그룹을 근거 확보 성공으로 처리하지 않습니다.
- 금액과 규정은 모두 데모 전용 가상 기준입니다. 실제 구매/계약에 사용하지 마세요.

## 재현성과 문서 품질

- 모든 문서는 시행일 `2026-09-01`, 버전 `1.0`으로 통일했습니다.
- 서로 다른 문서의 조항이 보완 관계를 가지도록 설계했습니다.
- PDF 문자는 이미지가 아닌 텍스트이므로 텍스트 추출·페이지 인용 테스트에 사용하기 좋습니다.
